# 🧾 Bomi POS (Frontend)

**Bomi POS** adalah aplikasi kasir modern berbasis web yang dirancang untuk membantu pemilik bisnis dalam mengelola transaksi, produk, dan outlet secara efisien — kapan saja dan di mana saja.

---

## 🚀 Fitur Utama

- 🔐 Autentikasi pengguna
- 🏪 Manajemen Outlet
- 📦 Manajemen Produk dan Stok
- 🌗 Dukungan **Dark Mode**
- 📱 Responsif di semua perangkat (Mobile & Desktop)
- 🎨 UI modern menggunakan **Tailwind CSS**
